# Panduan Staff

1. Login memakai email perusahaan. Izinkan kamera dan lokasi saat diminta.
2. Pada dashboard tekan **Buka Kamera**, arahkan kamera ke QR dinamis di kantor.
3. Setelah QR terbaca, jangan menutup halaman saat GPS divalidasi. Pesan sukses menampilkan check-in/check-out, status hadir, dan tipe kerja.
4. Scan pertama pada tanggal server menjadi check-in; scan kedua menjadi check-out. Scan berikutnya ditolak.
5. Dashboard menunjukkan jam/status hari ini, lokasi, dan riwayat terbaru.

Klasifikasi masuk: paling lambat 10:00 adalah Full Time; setelah 10:00 sampai tepat 14:00 adalah Hadir–Part Time; setelah 14:00 adalah Terlambat–Part Time. Jika gagal: pastikan QR belum berubah, berada dalam radius kantor, GPS aktif/akurasi memadai, koneksi stabil, dan situs dibuka melalui HTTPS. Jam HP tidak mengubah status karena server menggunakan WIB.
